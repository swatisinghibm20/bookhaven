# BookHaven

A responsive e-commerce bookstore front end built with React, Tailwind CSS and Vite.
Created with IBM Bob as the agentic IDE for the Applied AI Specialist – Front-end and Mobile capstone.

## Features

- Login / create account screen
- Catalogue with search, category, publisher, format and price filters, and sorting
- Cart with quantity steppers, recommendations and "Buy Again"
- Order history page
- Checkout, payment and confirmation flow

## Repository layout

| Path | Contents |
| --- | --- |
| `bookhaven/` | The React application |
| `01-login.html` … `06-confirmation.html` | Original HTML wireframes |

## Run locally

```bash
cd bookhaven
npm install
npm run dev      # http://localhost:5173
npm run build    # production build
```

## Scope

This repository contains the front end only, using mock data. There is no backend, database or payment processing.
